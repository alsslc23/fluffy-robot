# ADHD Interactive CBT Workbook

This workbook is designed for daily use to practice cognitive behavioral therapy (CBT) skills tailored to common ADHD challenges such as impulsivity, distractibility, and difficulty with planning. Use it as a living document—copy the daily template, fill it out, and track your progress over time.

## How to Use This Workbook
1. **Start your day** by duplicating the Daily Page template and filling in the quick-start checklist.
2. **During the day**, run short CBT cycles whenever you notice distractions, procrastination, or emotional spikes.
3. **End your day** with the reflection section to capture what worked and what you want to adjust tomorrow.
4. **Review weekly** using the Weekly Review page to identify patterns and fine-tune your plan.

### Distraction & Procrastination Log (CBT Cycle)
Use this mini-cycle whenever you catch yourself drifting or avoiding a task.

1. **Trigger/Situation**: What was happening? __________________________
2. **Thoughts/Beliefs**: "If I start, then…" __________________________
3. **Emotions/Intensity** (0-100): __________________________
4. **Body sensations** (restlessness, tension, etc.): __________________
5. **Behavior urge**: What did you want to do? ________________________
6. **CBT reframe**
   - Evidence for: _________________________________________________
   - Evidence against: _____________________________________________
   - Balanced thought: _____________________________________________
7. **Tiny action (2-5 min)**: ________________________________________
8. **Result**: What happened? How did the urge change? ________________

Repeat this cycle as often as needed. Keep it short—done is better than perfect.

### Focus Tools Menu
Use one option and set a 10–25 minute timer.
- **Body first**: 10 pushups/stretch, drink water, breath count 4-7-8 x 3.
- **Environmental tweak**: Put phone in another room, close tabs, full-screen the task, noise-canceling on.
- **Task shaping**: Define one verb + object (e.g., "email Alex", "outline slide 1").
- **Stimulus control**: Start in a low-distraction space; keep a sticky note of the next step.
- **Accountability**: Send a 1-line intention message; co-work online for 25 minutes.

### Emotion Regulation (when dysregulated)
- **Name it**: I feel ______ because ______.
- **Ground**: 5-4-3-2-1 senses or 30-second cold water splash.
- **Self-talk**: "I can start small; perfection is not required." 
- **Opposite action**: Do the smallest next step for 2 minutes.

## Quick Reference Cards
Print or save these as reminders.

### 5-Minute Start
1. Move body 1 minute
2. Drink water
3. Write the first verb + object
4. Open only the needed doc/app
5. Set a 10-minute timer

### When You Feel Overwhelmed
- Ask: "What is the first 2-minute move?"
- Break it: outline → fill → polish
- Use a body reset (breath 4-7-8 x3) then start a 5-minute timer.

### When You’re Procrastinating
- Identify the **fear** (boredom, failure, unclear steps).
- Run the CBT reframe (evidence for/against + balanced thought).
- Do a **tiny action** and promise a micro-reward.

### When Distracted
- Notice → Label distraction → Redirect with a 10-minute timer.
- Park non-urgent ideas in a capture list.
- Use environmental tweak + accountability if it persists.
